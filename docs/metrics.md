# 계산 지표 규칙 (자세히)

CLAUDE.md 의 요약을 보충하는 문서. 지표·그래프·인사이트를 만들 때 읽는다.

## 기본 지표

| 지표                  | 공식                | 표시 예                  |
| --------------------- | ------------------- | ------------------------ |
| CTR                   | 클릭 ÷ 노출         | `2.35%` (소수 둘째 자리) |
| CPC                   | 광고비 ÷ 클릭       | `1,234원`                |
| CPB (Cost Per Basket) | 광고비 ÷ 장바구니수 | `1,234원`                |
| CPA                   | 광고비 ÷ 전환       | `1,234원`                |
| ROAS                  | 매출 ÷ 광고비       | `350%`                   |

- 분모가 0이면 `-` (`NaN`·`Infinity` 노출 금지).
- 계산은 `src/utils/metrics.js` 한 곳에. 같은 폴더의 `metrics.test.js` 로 확인 (`node --test`).
- CPB 는 표 머리글에 "Cost Per Basket" 툴팁을 단다.

## 합계 규칙

- 합계 지표는 **합계끼리 나눈다**. 예: 전체 ROAS = 총 매출 ÷ 총 광고비.
  - ❌ 행별 ROAS 를 구해서 평균 내기 → 광고비가 작은 행이 결과를 왜곡한다.
- 일별·월별·매체별·캠페인별 묶음도 모두 같은 규칙.

## 퍼널 지표

| 지표            | 공식            |
| --------------- | --------------- |
| 담기율          | 장바구니 ÷ 클릭 |
| 장바구니→구매율 | 전환 ÷ 장바구니 |
| CVR             | 전환 ÷ 클릭     |
| 객단가          | 매출 ÷ 전환     |

- 매체별 퍼널 비교는 매체 필터와 무관하게 3개 매체(NAVER·META·GOOGLE)를 모두 보여주고, 가장 낮은 값을 표시한다.

## 기간 규칙 ("최근"은 오늘이 아니라 **데이터의 최근 날짜** 기준)

- 일자별 추이: 최근 날짜 + 이전 13일 = 14일. 데이터 없는 날은 0 이 아니라 빈칸(선이 끊김).
- 월 누적: 최근 월 + 이전 2개월 = 3개월. 표는 최신 월이 위.
- 전월 대비: CPA = 증감률(%), ROAS = 차이(%p). 3개월 범위 밖의 전월도 비교에 쓴다.
- 전주 대비: 최근 7일 vs 그 전 7일.

## 인사이트 규칙

- 합계 카드: 총 광고비 · 총 매출 · 전체 ROAS · 전체 CPA (구매당 비용이 장바구니당 비용보다 중요).
- 소재 ROAS 상위·하위 5: **광고비 10만 원 이상 + 전환 1건 이상**만 순위에 넣는다 (작은 표본의 우연 배제).
- 전환 0 인 소재는 경고로 따로 보여준다.

## 그래프

- 지표 1개당 그래프 1개 (이중 축 금지).
- 일자별·월별 추이는 같은 `TrendChart.jsx` 를 함께 쓴다.
