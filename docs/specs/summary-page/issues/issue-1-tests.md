### 값 약속

- `compareChange` 의 `direction`: `'up'` · `'down'` · `'same'`
- `compareChange` 의 `tone`: `'good'`(청록빛 초록) · `'bad'`(빨강) · `'neutral'`(회색)
- `compareChange` 의 `label`: `'개선'` · `'악화'` · `'변화'`(광고비) · `'변화 없음'`(값이 같을 때)
- 값이 같으면(`'same'`) 화면에는 회색 `– 변화 없음` 으로 보여준다.
- `summarizeCards` 카드 순서와 `key`·`goodWhen`:

  | 순서 | key       | title     | goodWhen |
  | ---- | --------- | --------- | -------- |
  | 1    | `cost`    | 총 광고비 | `'none'` |
  | 2    | `revenue` | 총 매출   | `'up'`   |
  | 3    | `roas`    | 전체 ROAS | `'up'`   |
  | 4    | `cpa`     | 전체 CPA  | `'down'` |

- 전주 데이터가 7일 미만이면 `previous` 와 `change` 는 모두 `null`.
- `fetchReports` 는 `import.meta.env` 를 써서 `node --test` 에서 실행할 수 없으므로 화면 확인으로 검사한다.

### 일부러 뺀 것 (YAGNI)

- 데이터 0건 화면, "최근 3일 기준" 표시, "비교할 지난주 데이터 없음" 문구 → "빈 데이터 화면" 이슈(#11)에서 다룬다. 단 S48(전주 6일 → `null`)은 ②번 줄의 "7일 모두 있을 때" 조건을 확인하는 경계값이라 넣었다.
- 매체 필터, CTR 등 다른 지표 → 이 이슈에 없다.
