## 1. 함수 모양

| 파일                 | 함수                 | 받는 값                        | 돌려주는 값                | 한 줄 설명                                                                 |

### 값 약속 (결정)

- **결정 1 — 오류 문구 모양:** `N번째 줄: {칸 이름} 칸은 …` / `N번째 줄: {칸 이름} 칸이 비어 있어요`. 칸마다 조사가 달라지는 것을 피한다.
  - 날짜: `N번째 줄: 날짜 칸은 2026-10-01 모양이어야 해요`
  - 매체: `N번째 줄: 매체 칸은 NAVER · META · GOOGLE 중 하나여야 해요`
  - 이름 빈칸: `N번째 줄: 소재 칸이 비어 있어요`
  - 이름 길이: `N번째 줄: 캠페인 칸은 100자 이하여야 해요`
  - 숫자: `N번째 줄: 광고비 칸은 0 이상의 숫자여야 해요`
  - 칸 빠짐: `필요한 칸이 없어요: 광고비, 매출` (양식 순서대로)
  - 데이터 없음: `데이터 줄이 없어요`
- **결정 2:** 숫자는 쉼표와 앞뒤 빈칸만 정리한다. `100원` 은 틀린 줄.
- **결정 3:** 매체는 `NAVER` · `META` · `GOOGLE` 만 (대소문자 무시). 한글 `네이버` 등은 틀린 줄.
- 줄 번호는 엑셀에서 보이는 번호다 (제목 줄 = 1, 첫 데이터 줄 = 2).
- 한 줄에 오류가 여러 개면 모두, 칸 순서대로 적는다. `errors` 는 줄 순서대로다.
- 칸이 빠지면 줄 검사를 하지 않고 바로 멈춘다 (`rows` 는 `[]`).
- 양식에 없는 칸은 무시한다. 제목 앞뒤 빈칸은 지운다.
- 이름(캠페인 · 광고그룹 · 소재)은 앞뒤 빈칸을 지운 뒤 검사한다.
- `rows` 의 각 줄은 api.md JSON 필드 11개 (`id` 없음).

## 2. 시나리오

**공통 예시 (S22 등)** — 양식 순서의 CSV

```
날짜,매체,캠페인,광고그룹,소재,광고비,노출,클릭,장바구니,전환,매출
2026/10/1,NAVER,가을 세일,검색_브랜드,소재A,"100,000",25000,600,80,20,350000
2026-10-02,meta,가을 세일,피드_리타겟,소재B,50000,30000,450,40,10,150000
```

→ `rows`

```js
;[
  {
    reportDate: '2026-10-01',
    media: 'NAVER',
    campaignName: '가을 세일',
    adGroupName: '검색_브랜드',
    creativeName: '소재A',
    cost: 100000,
    impressions: 25000,
    clicks: 600,
    carts: 80,
    conversions: 20,
    revenue: 350000,
  },
  {
    reportDate: '2026-10-02',
    media: 'META',
    campaignName: '가을 세일',
    adGroupName: '피드_리타겟',
    creativeName: '소재B',
    cost: 50000,
    impressions: 30000,
    clicks: 450,
    carts: 40,
    conversions: 10,
    revenue: 150000,
  },
]
```

### decodeCsv

| ID  | 분류 | 넣는 값                                    | 기대 결과 |

| ID  | 분류 | 상황                   | 넣는 값                                                  | 기대 결과                                                                                                          |
