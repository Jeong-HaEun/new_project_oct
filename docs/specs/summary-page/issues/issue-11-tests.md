## 1. 함수 모양

| 파일                  | 함수              | 받는 값            | 돌려주는 값                   | 한 줄 설명                                                                                       |
| --------------------- | ----------------- | ------------------ | ----------------------------- | ------------------------------------------------------------------------------------------------ |
| `src/utils/dates.js`  | `countRecentDays` | `rows, latestDate` | `0` ~ `7`                     | 최근 7일(`getWeekRanges(latestDate).current`) 안에 데이터가 있는 날 수. 기존 `countDays` 를 쓴다 |
| `src/utils/format.js` | `formatCoverage`  | `days`             | `null` 또는 `'최근 3일 기준'` | 7일이면 표시 안 함(`null`), 1~6일이면 "최근 N일 기준", 0일이면 "최근 7일 데이터 없음"            |

이미 있는 것: 전주 7일 미만이면 비교하지 않기는 `summarizeCards` 가 이미 한다 (`previous` · `change` 가 `null`, issue-1 S48). 0건 판단은 `getLatestDate([])` → `null` (issue-1).

### 값 약속 (결정)

- **결정 1:** 날 수는 **매체 필터를 거친 줄**로 센다 (카드 숫자와 같은 줄). 기준일은 전체 데이터의 최근 날짜 (이슈 #2 결정 A).
- **결정 2:** 중간에 빈 날이 있어도 "데이터가 있는 날 수" 로 센다. 10/1 · 10/3 · 10/7 만 있으면 "최근 3일 기준".
- **결정 3:** 0일(고른 매체가 최근 7일에 데이터 없음)이면 "최근 7일 데이터 없음". "최근 0일 기준" 은 어색하고, 그냥 두면 0원이 실제 성과처럼 보인다.

## 2. 시나리오

기준일은 모두 `'2026-10-07'` → 최근 7일 `2026-10-01` ~ `2026-10-07`.

### countRecentDays

| ID  | 분류 | 상황                | 넣는 값                            | 기대 결과               |
| --- | ---- | ------------------- | ---------------------------------- | ----------------------- |
| S1  | 정상 | 7일 꽉 참           | 10/01 ~ 10/07 하루 1줄씩           | `7`                     |
| S2  | 경계 | 6일                 | 10/02 ~ 10/07                      | `6`                     |
| S3  | 경계 | 8일 (창 밖 하루 더) | 09/30 ~ 10/07                      | `7` (9/30 은 세지 않음) |

| S5  | 정상 | 하루에 여러 줄      | 10/07 에 매체 · 소재가 다른 줄 3개 | `1` (날짜로 센다)       |

| S7  | 예외 | 데이터 없음         | `rows = []`, `latestDate = null`   | `0` (오류 없음)         |
