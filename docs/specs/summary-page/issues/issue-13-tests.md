## 1. 함수 모양

| 파일                   | 함수                   | 받는 값                             | 돌려주는 값                                              | 한 줄 설명                                                                             |
| ---------------------- | ---------------------- | ----------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `src/utils/dates.js`   | `getMonthToDateRanges` | `latestDate`                        | `{ current: { start, end }, previous: { start, end } }`  | 이번 달 1일~기준일, 지난달 같은 기간. 지난달에 그 날짜가 없으면 지난달 말일까지        |
| 〃                     | `formatMonthRange`     | `{ start, end }`                    | `'9월 1~7일'` · `'9월 1일'`                              | 막대 이름                                                                              |
| `src/utils/metrics.js` | `calcMomDelta`         | `key, current, previous`            | `{ value, unit }` 또는 `null`                            | ROAS 는 차이(`%p`), 나머지는 증감률(`%`). 부호 있는 값, 반올림 안 함                   |
| 〃                     | `summarizeMom`         | `rows, latestDate`                  | 4개 `[{ key, title, current, previous, change, delta }]` | 카드처럼 4지표. `change` 는 `compareChange`, `delta` 는 `calcMomDelta`                 |
| 〃                     | `buildPeriodBars`      | `item, previousLabel, currentLabel` | 막대 2개 또는 `null`                                     | WoW · MoM 공통 막대 데이터. `buildWowBars` 는 이 함수에 '지난주' · '이번 주' 를 넘긴다 |
| `src/utils/format.js`  | `formatDelta`          | `{ value, unit }` 또는 `null`       | `'25%'` · `'4%p'` · `''`                                 | 배지 숫자. 절댓값을 반올림 (방향은 배지 화살표가 보여 줌)                              |

### 값 약속 (결정)

- **결정 1:** #13 은 MoM 막대만. 월 누적 선 그래프는 #24.
- **결정 2:** 지난달 같은 기간에 **빠진 날이 하나라도 있으면** 비교하지 않는다 (`previous` · `change` · `delta` 모두 `null`). WoW 의 "7일 모두 있을 때만" 과 같은 생각.
- **결정 3:** 배지에 숫자를 넣는다: `▲ 4%p 개선` (ROAS), `▼ 38% 개선` (CPA), `▲ 25% 변화` (광고비). design.md 5-5 예시와 같다.
- 기준일은 전체 데이터 기준, 매체 필터를 거친 줄을 받는다 (이슈 #2 결정 A).
- 증감률 = (이번 − 지난) ÷ 지난 × 100. 지난 값이 0 이면 `null`.
- 막대 순서는 지난달 → 이번 달 (WoW 와 같음).

## 2. 시나리오

**예시 데이터 (S12, S14)** — 기준일 10/7, 매체 NAVER

- 9/1~9/7 매일 광고비 8,000 · 매출 30,000 · 구매 1 → 합계 56,000 / 210,000 / 7
- 10/1~10/7 매일 광고비 10,000 · 매출 35,000 · 구매 2 → 합계 70,000 / 245,000 / 14

### getMonthToDateRanges

| ID  | 분류 | 기준일         | 기대 결과                                                      |
| --- | ---- | -------------- | -------------------------------------------------------------- |
| S1  | 정상 | `'2026-10-07'` | 이번 `2026-10-01`~`2026-10-07`, 지난 `2026-09-01`~`2026-09-07` |
| S2  | 경계 | `'2026-10-01'` | 이번 `2026-10-01`~`2026-10-01`, 지난 `2026-09-01`~`2026-09-01` |
| S3  | 경계 | `'2026-03-28'` | 지난 `2026-02-01`~`2026-02-28`                                 |
| S4  | 경계 | `'2026-03-29'` | 이번 `2026-03-01`~`2026-03-29`, 지난 `2026-02-01`~`2026-02-28` |
| S5  | 경계 | `'2026-03-31'` | 지난 `2026-02-01`~`2026-02-28`                                 |
| S6  | 경계 | `'2026-01-15'` | 지난 `2025-12-01`~`2025-12-15` (해가 바뀜)                     |
