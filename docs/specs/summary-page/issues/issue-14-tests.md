## 1. 함수 모양

| 파일                   | 함수              | 받는 값            | 돌려주는 값                                                                                 | 한 줄 설명                                    |
| ---------------------- | ----------------- | ------------------ | ------------------------------------------------------------------------------------------- | --------------------------------------------- |
| `src/utils/metrics.js` | `calcCostPer`     | `cost, count`      | 숫자 또는 `null`                                                                            | 광고비 ÷ 개수 (CPC · CPB). 개수 0 이면 `null` |
| 〃                     | `summarizeTotals` | `rows`             | 11칸 `{ cost, impressions, clicks, carts, conversions, revenue, ctr, cpc, cpb, cpa, roas }` | 합계끼리 나눈다. 줄이 없으면 11칸 모두 `null` |
| 〃                     | `buildMonthTable` | `rows, latestDate` | 3줄 `[{ label, ...11칸 }]` (최신 월이 위)                                                   | 라벨은 `formatMonthLabel` (`'10월 (1~7일)'`)  |
| 〃                     | `buildDailyTable` | `rows, latestDate` | 14줄 `[{ label, ...11칸 }]` (최신 날짜가 위)                                                | 라벨은 `formatWeekdayDate` (`'10/7(수)'`)     |

다시 쓰는 기존 함수: `sumTotals` · `calcRate` (CTR) · `calcCpa` · `calcRoas`, `getRecentMonthRanges` · `formatMonthLabel` (#24), `getLast14Days` (#12), `formatWeekdayDate` (#18). 표시는 `formatWon` · `formatPercent` · `formatRate` (`2.35%`) · `formatCount`.

### 값 약속 (결정)

- **결정 1:** 데이터가 없는 달 · 날은 11칸 모두 `null` (`-`). 개수(광고비 · 노출 …)도 0 이 아니라 `-` — 그래프의 "0 으로 채우지 않음" 과 같은 규칙.
- **결정 2:** 데이터가 있으면 분모가 0 인 칸만 `null` (예: 구매 0건이면 CPA 만 `-`). 개수는 0 그대로.
- **결정 3:** 매체 필터를 거친 줄을 받는다. 기준일은 전체 데이터의 최근 날짜 (이슈 #2 결정 A).
- **화면 결정 (2026-10-14 사용자 승인):** 두 표는 같은 부품 `MetricTable.jsx` (design.md 5-7). 위치는 페이지 맨 아래 (BEST 소재 5 다음). CPB 머리글은 `<abbr title="Cost Per Basket">`. 표 상자 안에서만 가로 스크롤.
- **숫자 모양 (2026-10-14 사용자 결정):** 숫자는 줄이지 않고 원래 숫자 그대로 (`6,536,810원`). 단위(원 · %)는 카드처럼 작은 회색 글씨로 빼고, 숫자 칸은 오른쪽 정렬 + `tabular-nums` 로 자리를 맞춘다. 동요일 표(`WeekdayTrendTable`)도 같은 모양으로 맞춘다. 화면 모양만이라 계산 테스트는 늘지 않는다.
