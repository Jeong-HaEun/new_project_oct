## 1. 함수 모양

| 파일                 | 함수                    | 받는 값                   | 돌려주는 값                                 | 한 줄 설명                                     |
| -------------------- | ----------------------- | ------------------------- | ------------------------------------------- | ---------------------------------------------- |
| `src/utils/dates.js` | `getDownloadRange`      | `latestDate`              | `{ start, end }`                            | 기준일 포함 98일 (10/7 → 7/2~10/7)             |
| `src/utils/csv.js`   | `selectDownloadRows`    | `rows, media, latestDate` | 줄 목록                                     | 매체 필터 + 98일 + 날짜 오래된 순              |
| 〃                   | `buildReportsCsv`       | 줄 목록                   | 글자                                        | BOM + 제목 줄 + 원본 줄 (양식과 같은 칸, CRLF) |
| 〃                   | `buildDownloadFileName` | `media, range`            | `'adporter_META_2026-07-02_2026-10-07.csv'` | 전체(`null`)면 `adporter_전체_…`               |

### 값 약속 (결정)

- 범위는 **98일**(14주) — 동요일 비교에서 요일마다 14번씩 들어간다 (2026-10-13 90일 → 98일).
- 버튼 위치는 "데이터 기준일" 줄 오른쪽 (머리글이 휴대폰에서 꽉 차서). 원본 데이터 페이지(#19)가 생기면 옮긴다.
- 버튼 글자: `META · 최근 98일 내려받기` / `전체 · 최근 98일 내려받기`. 데이터가 0건이면 버튼을 숨긴다.
- 파일은 **원본 줄 그대로** (지표 칸 없음), `CSV_COLUMNS` 순서. 숫자는 쉼표 없이 (`100000`).
- 쉼표 · 따옴표 · 줄바꿈이 든 칸은 `"…"` 로 감싸고, 따옴표는 두 번(`""`) 쓴다.
- 줄 순서는 날짜 오래된 순. 같은 날짜끼리는 받은 순서를 지킨다.
- **받은 파일을 그대로 다시 올릴 수 있어야 한다:** `parseReportCsv(buildReportsCsv(rows))` 의 결과가 원래 줄과 같고 오류가 없다.
