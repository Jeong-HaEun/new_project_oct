## 1. 모양 결정 (2026-10-14 사용자 승인)

- **세로 깔때기**: 휴대폰 · 넓은 화면 모두 위 → 아래로 좁아지는 띠. 띠 안에 단계 이름과 숫자, 띠 사이에 비율 (`↓ CTR 1.44%`). 넓은 화면은 지금의 가로 한 줄 대신 가운데 정렬 + 최대 폭 `max-w-xl`.
- 띠 폭은 **고정** `w-full` → `w-5/6` → `w-2/3` → `w-1/2` (100% → 83% → 67% → 50%). 실제 비율대로 그리지 않는다 (노출 10,000 · 구매 15 면 구매 띠가 안 보임). 이슈 예시의 55% 대신 Tailwind 기본 눈금 `w-1/2` (design.md 4절 "기본 눈금만").
- 띠 색 `bg-primary-tint`, 단계 이름은 `text-ink` (연한 띠 위에서 `muted` 는 대비 4.5:1 미달), 숫자는 지금과 같은 큰 숫자.
- design.md 에 **5-11 퍼널 띠** 부품으로 클래스를 적는다.

## 2. 시나리오

새 계산 함수가 없어 자동 시나리오는 없다. 단계 숫자 · 비율 계산은 [issue-3-tests.md](issue-3-tests.md) 시나리오가 그대로 지킨다.
