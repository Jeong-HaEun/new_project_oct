다시 쓰는 기존 함수: `compareChange` (개선/악화, 합계 카드와 같은 규칙), `calcMomDelta` (배지 숫자: ROAS 는 %p, 나머지는 %), `CARDS` 목록, `filterByDateRange` · `sumTotals` · `calcRoas` · `calcCpa`. 화면은 `PeriodBars` (WoW · MoM 막대) 를 다시 쓴다.

### 값 약속 (결정)

- **결정 1:** 그날 데이터가 없으면 0 이 아니라 `null` (`-`). 광고비 · 매출까지 모두. 데이터가 있는데 광고비가 0 이면 광고비는 `0`, ROAS · CPA 만 `null`.
- **결정 2:** 하루 안의 여러 줄은 합계끼리 나눈다 (metrics.md 합계 규칙).
- **결정 3:** 지난주 같은 요일이 없으면 비교하지 않는다 (`previous` · `change` · `delta` 모두 `null` → "비교할 지난주 데이터 없음"). 기준일 값이 없을 때도 `change` · `delta` 는 `null`.
- **결정 4:** 매체 필터를 거친 줄을 받는다. 기준일은 전체 데이터의 최근 날짜 (이슈 #2 결정 A, 합계 카드와 같음).
- **화면 결정 (2026-10-14 사용자 승인):** 비교는 WoW · MoM 과 같은 **막대** (`PeriodBars`, 이름 `'9/30(수)'` · `'10/7(수)'`). 같은 요일 흐름은 **표** (최신 주가 위, 칸: 날짜 · 광고비 · 매출 · ROAS · CPA). 데이터 없는 주를 `-` 로 정확히 보여 준다.
- **결정 5 (2026-10-14 사용자 결정, #31):** 같은 요일 표는 처음 14주(98일)였으나 **최근 4주**로 줄인다. 14주는 대부분 비어 보이고, 동요일 흐름은 최근 4주면 충분하다. 98일 원본은 원본 데이터 페이지(`/data`)에서 본다.
