### 값 약속

- 기간은 화면 상태(`useState`), 매체는 주소(`?media=`). 페이지를 오가도 매체는 유지된다.
- 처음 열면 `last98`. 빠른 버튼을 누르면 날짜 칸도 그 기간으로 바뀐다. 날짜 칸을 직접 바꾸면 빠른 버튼은 아무것도 골라지지 않은 상태가 된다.
- 표는 최신 날짜가 위, 파일은 날짜 오래된 순 (같은 `selectRows` 결과를 뒤집어 그린다).
- 안내 문구: 빈 칸 → `시작일과 끝일을 골라 주세요`, 시작일 > 끝일 → `시작일이 끝일보다 늦어요`.
