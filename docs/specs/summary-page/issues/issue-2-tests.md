## 1. 함수 모양

| 파일                 | 함수 이름           | 받는 값                              | 돌려주는 값                               | 한 줄 설명                                                         |
| -------------------- | ------------------- | ------------------------------------ | ----------------------------------------- | ------------------------------------------------------------------ |
| `src/utils/media.js` | `MEDIA_LIST` (상수) | –                                    | `['NAVER', 'META', 'GOOGLE']`             | 필터 버튼 순서. 버튼과 검사가 같은 목록을 쓴다                     |
| 〃                   | `parseMedia`        | 주소의 `media` 값 (글자 또는 `null`) | `'NAVER'`·`'META'`·`'GOOGLE'` 또는 `null` | 주소 값 검사. 대소문자 무시, 없는 값이면 `null` (= "전체")         |
| 〃                   | `filterByMedia`     | `rows, media`                        | 줄 목록                                   | 그 매체 줄만 고르기. `media` 가 `null` 이면 전체를 그대로 돌려준다 |

### 값 약속

- 이미 있는 함수(`getLatestDate`, `summarizeCards` 등)는 새로 만들지 않고 그대로 쓴다.
- 주소 읽기·쓰기(`useSearchParams`)는 화면에서 한다. 함수는 "주소 글자 → 매체 값" 바꾸기만 한다.
- 주소가 틀려도(`KAKAO`) **주소창은 고치지 않고** 화면만 "전체"로 보여준다 (ADR-1).
- **기준일은 전체 데이터 기준이다 (결정 A).** `latestDate = getLatestDate(전체 rows)` 를 먼저 구하고, 카드는 `summarizeCards(filterByMedia(rows, media), latestDate)` 로 계산한다.
  - 이유: 매체를 바꿔도 같은 기간으로 비교할 수 있다. CSV 는 매체를 모아 한 번에 올리므로 업로드 지연 경고도 매체와 무관하다.

## 2. 시나리오

**예시 데이터 (S16~S18)** — 기준일 10/7, 10/1~10/7 매일

- NAVER: 광고비 10,000 · 매출 35,000 · 구매 2
- META: 광고비 5,000 · 매출 20,000 · 구매 1

### parseMedia

| ID  | 분류 | 상황                   | 넣는 값    | 기대 결과  |
| --- | ---- | ---------------------- | ---------- | ---------- |
| S1  | 정상 | META                   | `'META'`   | `'META'`   |
| S2  | 정상 | NAVER                  | `'NAVER'`  | `'NAVER'`  |
| S3  | 정상 | GOOGLE                 | `'GOOGLE'` | `'GOOGLE'` |
| S4  | 정상 | 소문자                 | `'meta'`   | `'META'`   |
| S5  | 경계 | 대소문자 섞임          | `'Meta'`   | `'META'`   |
| S6  | 경계 | 한 글자 모자람         | `'MET'`    | `null`     |
| S7  | 경계 | 한 글자 많음           | `'METAA'`  | `null`     |
| S8  | 예외 | 없는 매체              | `'KAKAO'`  | `null`     |
| S9  | 예외 | 주소에 media 없음      | `null`     | `null`     |
| S10 | 예외 | 값이 빈칸 (`/?media=`) | `''`       | `null`     |

S5~S7 은 "최대 −1 / 최대 / 최대 +1" 을 글자 수로 바꾼 것이다.

### filterByMedia

| ID  | 분류 | 상황                 | 넣는 값                                     | 기대 결과       |
| --- | ---- | -------------------- | ------------------------------------------- | --------------- |
| S11 | 정상 | 섞인 데이터에서 META | NAVER 2줄 · META 3줄 · GOOGLE 1줄, `'META'` | 3줄, 모두 META  |
| S12 | 정상 | 전체                 | 같은 6줄, `null`                            | 6줄 그대로      |
| S13 | 경계 | META 0줄             | NAVER 2줄 · GOOGLE 1줄, `'META'`            | `[]`            |
| S14 | 경계 | META 1줄             | NAVER 2줄 · META 1줄, `'META'`              | 1줄 (그 META줄) |
| S15 | 예외 | 데이터 없음          | `[]`, `'META'`                              | `[]`            |

### 카드와 합쳐 보기 (`summarizeCards(filterByMedia(rows, media), latestDate)`)

| ID  | 분류 | 상황                                    | 넣는 값                                               | 기대 결과                                                 |
| --- | ---- | --------------------------------------- | ----------------------------------------------------- | --------------------------------------------------------- |

## 3. 대조표

| 체크리스트 줄                                                        | 시나리오 | 검사 방법                                                     |
| -------------------------------------------------------------------- | -------- | ------------------------------------------------------------- |
| ① META 를 고르면 카드가 META 데이터로만 바뀌고 주소가 `/?media=META` | S11~S18  | 자동(node --test) + 화면 확인 (버튼을 누르면 주소가 바뀌는지) |
| ② `/?media=META` 로 들어오거나 새로고침하면 META 가 골라진 채 열림   | S1~S3    | 자동(node --test) + 화면 확인 (새로고침)                      |
| ③ `/?media=meta`(소문자) → META                                      | S4, S5   | 자동(node --test) + 화면 확인                                 |
| ④ `/?media=KAKAO` → "전체"                                           | S6~S10   | 자동(node --test) + 화면 확인 (주소창은 KAKAO 그대로 남는지)  |

체크리스트에 없는 `vercel.json`(배포 시 새로고침 404 방지, ADR-1)은 배포 이슈에서 만든다.
