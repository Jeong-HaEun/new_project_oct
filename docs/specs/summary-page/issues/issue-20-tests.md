## 1. 함수 모양

| 파일                   | 함수           | 받는 값                                   | 돌려주는 값                                                                                              | 한 줄 설명                                             |
| ---------------------- | -------------- | ----------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| `src/utils/metrics.js` | `buildWowBars` | 카드 하나 (`summarizeCards` 결과의 한 칸) | `[{ key: 'previous', label: '지난주', value }, { key: 'current', label: '이번 주', value }]` 또는 `null` | 막대 2개 데이터. 지난주 값이 없으면 `null` (비교 불가) |

### 값 약속

- 새 계산은 하지 않는다. `summarizeCards` 가 이미 가진 `current` · `previous` 를 그래프 모양으로 바꾸기만 한다.
- 막대 순서는 **지난주 → 이번 주** (위 → 아래, 시간 순서).
- `previous` 가 `null` 이면 (전주 7일 미만 또는 계산 불가) `null` → 화면은 "비교할 지난주 데이터 없음".
- `current` 만 `null` 이면 막대 데이터는 만들고 그 값만 `null` → 화면은 이번 주 막대 없이 `-`.
- 개선/악화 배지는 카드의 `change`(`compareChange`)를 그대로 쓴다.
- 그래프 모양은 design.md 5-8 막대 규칙 (가로 막대, 이번 주 `primary` · 지난주 `muted`, 0 에서 시작, 값 · 기간 이름 글자 표시).
