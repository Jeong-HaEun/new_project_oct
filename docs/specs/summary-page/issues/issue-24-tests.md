- 이슈: GitHub #24 「요약 페이지: 최근 3개월 월 누적 선 그래프」 (#13 에서 나눔)
- 근거: [prd.md](../prd.md) 사용자 이야기 5 · ADR-4 (흐름은 선, 값이 없으면 선을 끊음), [metrics.md](../../../metrics.md) 기간 규칙 (월 누적 = 최근 월 + 이전 2개월) · 그래프 (`TrendChart.jsx` 공유), [design.md](../../../design/design.md) 5-8 · 7절
- 다음 단계: `/tdd-red 24` 가 이 파일을 읽어 테스트 코드를 만든다.

## 1. 함수 모양

| 파일                   | 함수                   | 받는 값            | 돌려주는 값                             | 한 줄 설명                                                         |
| ---------------------- | ---------------------- | ------------------ | --------------------------------------- | ------------------------------------------------------------------ |
| `src/utils/dates.js`   | `getRecentMonthRanges` | `latestDate`       | 3개 `[{ start, end }]` (오래된 달 먼저) | 그 전 2개월은 1일~말일, 이번 달은 1일~기준일                       |
| 〃                     | `formatMonthLabel`     | `{ start, end }`   | `'9월'` · `'10월 (1~7일)'`              | 한 달이 다 찼으면 달만, 아니면 기간도 함께                         |
| `src/utils/metrics.js` | `summarizeMonthTrend`  | `rows, latestDate` | 3개 `[{ label, roas, cpa }]`            | 달마다 합계끼리 나눈다. 계산할 수 없으면 `null` → 그래프 선이 끊김 |

다시 쓰는 기존 함수: `cardValues` (기간 합계 → ROAS · CPA), `calcRoas` · `calcCpa`.

### 값 약속 (결정)

- **결정 1:** 오래된 달이 먼저 (그래프 왼쪽 → 오른쪽).
- **결정 2:** 데이터가 없는 달 · 광고비 0 인 달은 ROAS `null`, 구매 0 인 달은 CPA `null`. 그래프는 그 점을 비우고 선을 끊는다 (`connectNulls={false}`), 0 으로 그리지 않는다.
- **결정 3:** 기준일이 말일이면 이번 달도 다 찬 것이라 "10월" 만 적는다.
- **결정 4:** 매체 필터를 거친 줄을 받는다. 기준일은 전체 데이터의 최근 날짜 (이슈 #2 결정 A).
- **화면 결정 (2026-10-14 사용자 승인):** `TrendChart.jsx` (#12 에서도 다시 씀) 로 CPA · ROAS 그래프 2개, 모바일은 위아래 · 넓은 화면은 나란히 (`grid gap-3 md:grid-cols-2 md:gap-4`). 선 `var(--color-primary)` 2px, 마지막 점 옆에 값. 위치는 동요일 비교 아래, 퍼널 분석 위.
