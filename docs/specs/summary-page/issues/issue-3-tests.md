## 1. 함수 모양

| 파일                   | 함수 이름              | 받는 값                  | 돌려주는 값                      | 한 줄 설명                                                                      |
| ---------------------- | ---------------------- | ------------------------ | -------------------------------- | ------------------------------------------------------------------------------- |
| `src/utils/metrics.js` | `calcRate`             | `numerator, denominator` | `2.35` (퍼센트 숫자) 또는 `null` | 단계 비율 = 뒤 단계 ÷ 앞 단계 × 100. 앞 단계가 0 이면 `null`                    |
| 〃                     | `summarizeFunnel`      | `rows, latestDate`       | `{ stages, rates }`              | 최근 7일 단계 흐름. 매체 필터를 거친 줄을 받는다                                |
| 〃                     | `compareFunnelByMedia` | `rows, latestDate`       | `{ byMedia, lowest }`            | 3개 매체의 단계 비율과 단계별 "최저" 매체. **필터와 무관하게 전체 줄**을 받는다 |
| `src/utils/format.js`  | `formatRate`           | 숫자 또는 `null`         | `'2.35%'` 또는 `'-'`             | 단계 비율 표시 (소수 둘째 자리)                                                 |
| 〃                     | `formatCount`          | 숫자                     | `'7,000'`                        | 단계 숫자 표시 (쉼표, 단위 없음)                                                |

이미 있는 `getWeekRanges` · `filterByDateRange` · `sumTotals` · `filterByMedia` · `MEDIA_LIST` 를 그대로 쓴다.

### 돌려주는 값 모양

```js
summarizeFunnel(rows, '2026-10-07') →
{
  stages: [
    { key: 'impressions', label: '노출', count: 7000 },
    { key: 'clicks', label: '클릭', count: 350 },
    { key: 'carts', label: '장바구니', count: 70 },
    { key: 'conversions', label: '구매', count: 14 },
  ],
  rates: [
    { key: 'ctr', label: 'CTR', value: 5 },
    { key: 'cartRate', label: '담기율', value: 20 },
    { key: 'purchaseRate', label: '장바구니→구매율', value: 20 },
  ],
}

compareFunnelByMedia(rows, '2026-10-07') →
{
  byMedia: [
    { media: 'NAVER', rates: { ctr: 3, cartRate: 20, purchaseRate: 20 } },
    { media: 'META', rates: { ctr: 2, cartRate: 25, purchaseRate: 30 } },
    { media: 'GOOGLE', rates: { ctr: 4, cartRate: 10, purchaseRate: 25 } },
  ],
  lowest: { ctr: ['META'], cartRate: ['GOOGLE'], purchaseRate: ['NAVER'] },
}
```

### 값 약속 (결정)

- 비율: CTR = 클릭 ÷ 노출, 담기율 = 장바구니 ÷ 클릭, 장바구니→구매율 = 구매 ÷ 장바구니 (metrics.md). 합계끼리 나눈다.
- 계산 순서는 `numerator * 100 / denominator` (× 100 을 먼저). `0.0235 * 100` 처럼 소수 오차가 생기지 않게 한다.
- 기준일은 이슈 #2 와 같이 **전체 데이터 기준**이다.
- `byMedia` 순서는 `MEDIA_LIST` 순서(NAVER · META · GOOGLE)로 고정. 데이터가 없는 매체도 비율 `null` 로 들어간다.
- **결정 1:** 세 비율 모두 소수 둘째 자리로 표시한다 (`formatRate`). 기존 `formatPercent`(정수, ROAS 용)와 따로 둔다.
- **결정 2:** 최저가 동점이면 동점인 매체 **모두**에 "최저" 를 단다.
- **결정 3:** 비율 값이 있는(`null` 이 아닌) 매체가 **2개 이상**일 때만 최저를 고른다. 1개 이하면 `[]`.
- **결정 4:** 비교한 매체가 **모두** 최저(전부 같은 값)이면 `[]`. 고칠 곳을 알려주는 정보가 없기 때문이다. 일부만 동점이면 결정 2 대로 모두 표시한다.
- `null` 비율은 최저 비교에서 뺀다.

## 2. 시나리오
