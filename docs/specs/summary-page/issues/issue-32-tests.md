## 1. 함수 모양

| 파일                 | 함수                           | 받는 값                             | 돌려주는 값                                                | 한 줄 설명                                         |
| -------------------- | ------------------------------ | ----------------------------------- | ---------------------------------------------------------- | -------------------------------------------------- |
| `src/utils/dates.js` | `WEEKDAY_OPTIONS` (상수)       | —                                   | `[{ value: 1, label: '월' }, … { value: 0, label: '일' }]` | 버튼 순서 (월요일 먼저)                            |
| 〃                   | `toggleWeekday`                | `weekdays, day`                     | 새 배열 (월요일 먼저 순서)                                 | 켜고 끄기. 다 끄거나 7개 다 켜면 `[]` (전체)       |
| 〃                   | `formatWeekdays`               | `weekdays`                          | `'토일'` · `''`                                            | 월요일 먼저 순서로 붙여 쓴다. 전체(`[]`)면 빈 글자 |
| `src/utils/csv.js`   | `selectRows` (바꿈)            | `rows, media, range, weekdays = []` | 줄 목록                                                    | 요일 거르기 추가. `[]` 이면 지금과 같다            |
| 〃                   | `buildDownloadFileName` (바꿈) | `media, range, weekdays = []`       | 파일 이름                                                  | 요일이 있으면 매체 뒤에 넣는다                     |

요일 번호는 자바스크립트 `getDay()` 를 따른다: 일 = 0, 월 = 1 … 토 = 6.

### 값 약속 (결정)

- **결정 1:** `[]` = 전체. 마지막 하나를 끄면 전체로 돌아간다.
- **결정 2:** 7개를 다 켜면 `[]` (전체) 로 바꾼다. 같은 뜻인데 [전체] 버튼이 안 켜져 있으면 헷갈린다.
- **결정 3:** 요일 순서는 항상 월요일 먼저 (누른 순서와 무관). 파일 이름이 늘 같아진다 (`월일` 만, `일월` 은 안 생김).
- **결정 4:** 요일을 안 고르면 표와 파일 이름이 지금과 똑같다. 기존 테스트(download.test.js 등)도 그대로 통과해야 한다.
- **화면 결정:** 요일 버튼은 매체 필터와 같은 알약 (5-4), 고른 것은 `aria-pressed`. 고른 요일은 화면 상태(`useState`), 주소에는 매체만. 줄이 없으면 내려받기 버튼을 숨기고 "이 기간 · 요일에 데이터가 없어요".
