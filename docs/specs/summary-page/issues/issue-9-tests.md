### 값 약속 (결정)

- 제목 줄은 test1007 샘플 CSV 와 **같은 이름 · 같은 순서**: `날짜,매체,캠페인,광고그룹,소재,광고비,노출,클릭,장바구니,전환,매출`. test1007 에서 쓰던 CSV 를 그대로 올릴 수 있게 한다. 파일에는 `전환`, 화면에서만 "구매".
- 맨 앞에 BOM(`﻿`)을 붙인다 (엑셀 한글 깨짐 방지). 줄바꿈은 CRLF(`\r\n`, CSV 표준).
- **결정 1:** 예시 줄 없이 **제목 줄만** 담는다. 예시를 지우지 않고 올리면 가짜 데이터가 쌓이기 때문이다.
- **결정 2:** 파일 이름은 `adporter_양식.csv`. 90일 파일(`adporter_META_…csv`)과 앞부분이 같아 한 폴더에서 같이 정렬된다.
- `downloadText` 는 `src/utils/` 에 두지만 순수 함수가 아니다 (브라우저 `Blob` · 링크 클릭 사용). #15 90일 내려받기도 함께 쓴다.

## 2. 시나리오 (`buildTemplateCsv` · `CSV_COLUMNS` · `TEMPLATE_FILE_NAME`)

| ID  | 분류 | 상황       | 넣는 값                | 기대 결과                                                                                                                                     |
| --- | ---- | ---------- | ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| S1  | 정상 | 맨 앞 글자 | `buildTemplateCsv()`   | 첫 글자가 `'﻿'` (BOM)                                                                                                                         |
| S2  | 정상 | 제목 줄    | `buildTemplateCsv()`   | BOM 다음 첫 줄이 `'날짜,매체,캠페인,광고그룹,소재,광고비,노출,클릭,장바구니,전환,매출'`                                                       |
| S3  | 경계 | 전체 내용  | `buildTemplateCsv()`   | 정확히 `'﻿' + 제목 줄 + '\r\n'` (예시 줄 0개)                                                                                                 |
| S4  | 경계 | 칸 수      | `CSV_COLUMNS`          | 정확히 11개 (10개 · 12개면 실패)                                                                                                              |
| S5  | 정상 | 필드 짝    | `CSV_COLUMNS` 의 field | `reportDate, media, campaignName, adGroupName, creativeName, cost, impressions, clicks, carts, conversions, revenue` (api.md 순서, `id` 제외) |
| S6  | 정상 | 파일 이름  | `TEMPLATE_FILE_NAME`   | `'adporter_양식.csv'`                                                                                                                         |

S4 · S5 는 "11개 −1 / 11개 / 11개 +1" 경계를 막는다. 칸이 하나 빠지거나 많아지면 업로드 양식이 서버와 어긋난다.
