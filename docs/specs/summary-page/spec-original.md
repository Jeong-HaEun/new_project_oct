# 요약 페이지 (/)

마케터가 아침에 열어서 어제까지 광고가 돈을 벌었는지 10초 안에 알 수 있어야 한다.
(참고: test1007 요약 페이지를 다시 만드는 것. 백엔드는 test1007 것을 그대로 사용)

- 총 광고비, 총 매출, 전체 ROAS, 전체 CPA 카드를 제일 위에
- 각 카드에 최근 7일 값과 지난주보다 좋아졌는지/나빠졌는지
- 매체별로 어디서 사람들이 빠져나가는지 (퍼널, 가장 낮은 단계 표시)
- 최근 14일 CPA·ROAS 추이 그래프
- 최근 3개월 월 누적 추이 + 전월 대비
- 월별·일별 데이터 표
- 매체 필터 (전체 / NAVER / META / GOOGLE)
- CSV 업로드, 양식 내려받기 버튼
- 모바일에서도 보여야 함 (test1007 에서는 못 함)
