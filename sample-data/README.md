# 대시보드 시연용 가상 데이터

`demo_reports_2026-08-15_2026-10-15.csv`는 실제 광고 실적이나 고객 정보가 아닌 임의 생성 데이터입니다.

- 기간: 2026년 8월 15일~10월 15일, 62일
- 매체: NAVER, META, GOOGLE
- 매체별 캠페인 3개, 캠페인별 그룹 2개, 그룹별 소재 2개
- 총 2,232행. 주말·프로모션·소재 개선·소재 피로에 따른 가상 성과 차이 포함

## 사용

1. GitHub에서 CSV 파일을 열고 **Download raw file**로 다운로드합니다(복사·붙여넣기 대신 파일 다운로드).
2. 배포된 Adporter에 로그인합니다.
3. **CSV 업로드**에서 해당 파일을 선택합니다.
4. ‘새로 2232줄’ 메시지와 보고서 표시를 확인합니다. 기존에 같은 항목이 있으면 수정 건수로 집계됩니다.

같은 파일을 다시 업로드하면 같은 날짜·매체·캠페인·그룹·소재를 덮어씁니다. 다른 데이터는 삭제하지 않습니다.
재생성: 저장소 루트에서 `python scripts/generate_demo_reports.py` 실행. 고정 난수 시드로 같은 파일을 생성합니다.
